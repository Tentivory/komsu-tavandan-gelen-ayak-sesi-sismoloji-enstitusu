# Komşu Tavandan Gelen Ayak Sesi Sismoloji Enstitüsü

> Üst kattan gelen her takırtıyı bilimsel olay, tavanı fay hattı, terliği resmi sismograf sayan ulusal kurum.

Bu yazılım şaka değildir. Şaka olsaydı tavan susardı.

## Ne yapar?

- Rastgele bir **Terlikölçer (Tk)** şiddeti üretir.
- Sarsıntıyı sınıflandırır.
- Komşuyu plaka, ayak sesini deprem, çayı acil müdahale ilan eder.
- Ekrana çok ciddi bir bülten basar.

## Kuruluş

```bash
python3 enstitu.py
```

Bağımlılık yoktur. Python 3 yeter. Tavan gerekir.

## Ölçek

| Tk   | Anlam                                      |
|------|--------------------------------------------|
| < 2  | uçuşan toz / ihmal edilebilir terlik       |
| 2–4  | orta şiddetli ev içi protokol ihlali       |
| 4–6  | ciddi tavan egemenliği krizi               |
| ≥ 6  | milli oturma odası acil durumu             |

## Yasal uyarı

Enstitü gerçek bir kamu kurumu değildir. Gerçek bir kamu kurumu olsaydı randevu altı ay sonraya çıkardı.

Tavanlar vatandaş değildir. Bu repoda vatandaştır.
